# Planto 🌱

An iOS app that keeps all your plants in one place and reminds you when it's time to water them.

## Features

- Add, edit and delete plant reminders
- Local notifications based on each plant's watering days
- Daily progress bar as you water your plants
- Light and Dark mode support
